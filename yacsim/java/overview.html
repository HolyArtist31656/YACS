YACSim — Yet Another CAD Simulator

YACSim is a lightweight, zero-extra-dependency 3D CAD simulation library for WPILib 2027 (2027_alpha7, Java 25, Commands v3) designed to pair with YAMS and AdvantageScope on the 2 GB RAM SystemCore.

Quickstart

{@code
CadRobotConfig config =
    new CadRobotConfig("MyRobot")
        .withChassisAsset(new CadAssetConfig(modelsDir.resolve("chassis.glb")))
        .withDrivetrainPoseSupplier(drive::getPose)
        .withExtensionMargin(0.35, 1.85)
        .ignoreRestingOverlaps()
        .autoGroundChassis()
        .withAutoInstallToAdvantageScope()
        .addComponent(
            new CadComponentConfig("Arm", new CadAssetConfig(modelsDir.resolve("arm.glb")))
                .withParentComponent("Chassis")
                .withPoseSupplier(
                    YamsCommands3Bridge.fromYamsArm(
                        arm, new Translation3d(0.2, 0.0, 0.45), MotionAxis.Y)));

CadRobotMechanism cadSim = new CadRobotMechanism(this, config);
}

NetworkTables Telemetry (Default Root: /YACSim)

  • /YACSim/RobotPose (Pose2d) — 2D field pose of the drivetrain.
  • /YACSim/RobotPose3d (Pose3d) — 3D field pose including gyro pitch and roll.
  • /YACSim/ComponentPoses (Pose3d[]) — Articulated mechanism poses in registration order.
  • /YACSim/CollisionActive (boolean) — true when any OBB or envelope collision is active.
  • /YACSim/CollisionDetails (String[]) — Active collision pairs and penetration depths in meters.
