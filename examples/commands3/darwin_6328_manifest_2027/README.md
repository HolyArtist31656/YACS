# FRC 6328 "Darwin" — Manifest-Driven CAD Example (`yacsim-robot.json`)

This example demonstrates **Phase 1 CAD-to-YACSim automation** using FRC Team 6328 Mechanical Advantage's 2026 robot **Darwin** ([Onshape Assembly](https://cad.onshape.com/documents/2da573df9d139d7a1e0f08a8/w/5266e52966df9f56fcb472f0/e/15a6a42133f059b818ad5264), [RobotCode2026Public](https://github.com/Mechanical-Advantage/RobotCode2026Public)).

## What Comes From CAD (`yacsim-robot.json`) vs. Java

| Source | Parameters |
| :--- | :--- |
| **`src/main/deploy/yacsim/darwin/yacsim-robot.json`** (CAD-extracted) | All `.glb` mesh paths, AdvantageScope zeroed rotations/positions, exact CAD mass & principal inertia (`Ixx`/`Iyy`/`Izz`), joint pivot origins, motion axes, inversions, hard & soft travel limits, starting positions, arm lengths, elevator drum radius, carriage mass, all 5 roller/flywheel radii & MOI, extension margins, and camera frustum |
| **Java Mechanism Classes** (Electrical & Controls only) | TalonFX CAN IDs (`11–18`), `DCMotor` types (`KrakenX60` / `KrakenX60Foc`), gearbox reduction ratios, current limits, and PID/Feedforward gains |

## Quick Start (Windows PowerShell)

```powershell
# 1. Publish YACSim v2027.2.1-alpha1 locally from YACS/vendordep
cd ..\..\..\vendordep
.\gradlew publish generateVendordepJson "-Dorg.gradle.java.home=C:\Users\Public\wpilib\2027_alpha7\jdk"

# 2. Download Darwin .glb meshes & copy vendordeps
cd ..\examples\commands3\darwin_6328_manifest_2027
.\setup_darwin_manifest_cad.ps1

# 3. Launch simulation (enforces -Xmx256m SystemCore parity)
.\gradlew run --refresh-dependencies "-Dorg.gradle.java.home=C:\Users\Public\wpilib\2027_alpha7\jdk"
```

On startup, YACSim automatically generates `advantagescope-assets/Robot_DarwinManifest/` and `advantagescope-assets/darwin-manifest-layout.json` directly from `yacsim-robot.json`.

## 3D Spinning Rollers in AdvantageScope

This example ships with 5 color-striped 3D spinning roller `.glb` meshes generated by `tools/onshape-exporter/yacsim_onshape_exporter.py --augment-rollers`:
- `model_4.glb` — **FlywheelMesh** (Red/Yellow)
- `model_5.glb` — **KickerFrontMesh** (Blue/White)
- `model_6.glb` — **KickerBackMesh** (Green/White)
- `model_7.glb` — **HopperRollerMesh** (Orange/Charcoal)
- `model_8.glb` — **IntakeRollerMesh** (Purple/Gold, automatically mounted on the moving `Slamtake` arm!)

Copy `advantagescope-assets/Robot_DarwinManifest/` into AdvantageScope's User Assets folder (`Help -> Show Assets Folder`) and open `advantagescope-assets/darwin-manifest-layout.json` to watch all 4 articulated mechanisms and all 5 rollers move together in 3D.
